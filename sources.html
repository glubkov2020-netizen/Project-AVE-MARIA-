Версия: 5.0 Дата: 2026 Статус: Открытый реестр

1.Введение

Настоящий реестр содержит перечень источников, которые могут использоваться для получения данных о годовой выработке электроэнергии по субъектам Российской Федерации.

Платформа не поставляет данные. Все цифры, отображаемые в интерфейсе — результат ввода пользователя. Реестр описывает где можно получить официальные данные, но не заменяет их.

Важно. При использовании данных в официальных отчётах необходимо указывать конкретный источник, дату выгрузки и номер страницы/таблицы. Для каждого региона рекомендуется сверка минимум по двум источникам.

5.Методика сбора

Рекомендуемая последовательность:

  1. Определить регионы — список субъектов, по которым собираются данные.
  2. Определить годы — обычно 2015–2023.
  3. Собрать из официального источника (Минэнерго / СО ЕЭС) — основные значения.
  4. Сверить с Росстатом — расхождения не должны превышать 3–5%.
  5. Сверить с региональными — для регионов с крупными станциями.
  6. Зафиксировать источник — в поле «Примечание» указать документ, год, страницу.
  7. Загрузить в платформу — CSV/JSON или таблица ввода.
  8. Прогнать «Паспорт данных» — проверить пропуски и скачки.
Правило двух источников. Для официальных отчётов каждое значение рекомендуется подтвердить минимум по двум независимым источникам.

7.О seed-базе data.js

Файл data.js содержит предзаполненный набор из 10 регионов × 10 лет (2014–2023).

Важно. Все цифры в data.js имеют статус «оценка» и требуют проверки по первоисточникам перед использованием в официальных отчётах.

Как обновить

  1. Откройте data.js в любом редакторе.
  2. Найдите нужную строку: {region:"Москва", year:2019, value:67.2, status:"оценка", note:"требует проверки"}.
  3. Замените value на официальное значение.
  4. Замените status на "факт".
  5. В note укажите источник: "Отчёт Минэнерго 2019, табл. 4.2, стр. 38".

8.Как цитировать

При использовании данных платформы в отчёте рекомендуется указывать:

  • Первоисточник данных — например, «Минэнерго России, Отчёт о функционировании ЕЭС, 2020, табл. 4.2».
  • Дату выгрузки — когда скачаны данные.
  • Платформу — «Расчёт выполнен в платформе „Выработка ЭЭ по регионам РФ", v5.0».

Пример цитирования

«Выработка электроэнергии по регионам РФ, 2014–2023 гг. Источник: Минэнерго России, СО ЕЭС. Обработка и визуализация: платформа „Выработка ЭЭ по регионам РФ", v5.0, 2026.»
