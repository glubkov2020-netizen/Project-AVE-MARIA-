Методика расчётов

Версия: 5.0 Дата: 2026 Статус: Открытая методика

1.Введение

Настоящий документ описывает все математические методы, применяемые в платформе «Выработка ЭЭ по регионам РФ». Каждая формула сопровождается описанием обозначений, допущений и примеров использования.

Документ предназначен для:

  • аналитиков, проверяющих расчёты платформы;
  • аудиторов, готовящих официальные отчёты;
  • разработчиков, расширяющих платформу.
Открытость. Все формулы открыты, реализованы в JavaScript, доступны для проверки в консоли браузера. При расхождении с ручным расчётом — приоритет за ручным.

2.Единицы измерения

3.Описательные статистики

3.1. Среднее арифметическое

x̄ = (Σ xᵢ) / n n — число наблюдений; xᵢ — i-е значение. Показывает «центральное» значение ряда. Чувствительно к выбросам.

3.2. Медиана

Me = x₍₍ₙ₊₁₎/₂₎ (n — нечётное) Me = (x₍ₙ/₂₎ + x₍ₙ/₂₊₁₎) / 2 (n — чётное) Ряд отсортирован по возрастанию. Устойчива к выбросам. Рекомендуется для оценки «типичного» уровня.

3.3. Стандартное отклонение (выборочное)

σ = √[ Σ (xᵢ − x̄)² / (n − 1) ] Знаменатель (n − 1) — поправка Бесселя для несмещённой оценки. Мера разброса. Используется в z-score.

3.4. Коэффициент вариации

CV = (σ / x̄) × 100% Относительная мера разброса. Позволяет сравнивать ряды с разными средними. При x̄ = 0 не определён.

3.5. Минимум, максимум, размах

Min = min(xᵢ); Max = max(xᵢ); R = Max − Min

3.6. CAGR — среднегодовой темп роста

CAGR = [(x_end / x_start)^(1/n) − 1] × 100% n — число лет между крайними годами ряда. Применяется только если оба значения положительные.

4.Тренды

Платформа строит три типа трендов и автоматически выбирает лучший по R².

4.1. Линейный тренд (МНК)

ŷ = a + b·t b = Σ (tᵢ − t̄)(yᵢ − ȳ) / Σ (tᵢ − t̄)² a = ȳ − b·t̄ t — порядковый номер года (0, 1, 2, …); y — значение. Коэффициент b — средний годовой прирост (в единицах y).

4.2. Полиномиальный тренд 2-й степени

ŷ = a₀ + a₁·t + a₂·t² Коэффициенты находятся через решение системы нормальных уравнений методом Гаусса. Используется при выраженном ускорении/замедлении роста. При малом n (менее 5) может быть неустойчив.

4.3. Экспоненциальный тренд

ŷ = a · e^(b·t) МНК применяется к ln(y), затем a = e^(ln a). Требует положительных значений. Хорош для быстрорастущих рядов.

4.4. Прогноз

ŷ_прогноз(t) = модель(t) для t > t_last Прогноз на 1, 2, 3, 5 лет вперёд по лучшей модели. Прогноз — экстраполяция, не учитывает структурные сдвиги. Всегда помечается в отчётах.

5.Качество модели

5.1. R² — коэффициент детерминации

R² = 1 − SS_res / SS_tot SS_res = Σ (yᵢ − ŷᵢ)² SS_tot = Σ (yᵢ − ȳ)² Доля дисперсии, объяснённая моделью. 1 — идеальное совпадение, 0 — модель не объясняет ничего. При SS_tot = 0 R² принимается за 1.

5.2. MAPE

MAPE = (100/n) × Σ |(yᵢ − ŷᵢ) / yᵢ| Средняя абсолютная процентная ошибка. Меньше — лучше. Не определён при yᵢ = 0.

5.3. Выбор лучшей модели

Сравниваются три модели (линейная, полином-2, экспонента). Выбирается модель с наибольшим R². При равенстве R² (что маловероятно) — приоритет линейной.

6.Аномалии

Применяются три независимых метода. Значение помечается как аномалия, если срабатывает хотя бы один.

6.1. z-score

z = (x − x̄) / σ |z| > 2 — выброс; |z| > 3 — сильный выброс. Чувствителен к выбросам (сам выброс искажает σ). Работает для нормально распределённых рядов.

6.2. IQR-метод (ящик с усами)

Q1 = 25-й перцентиль Q3 = 75-й перцентиль IQR = Q3 − Q1 Выброс: x < Q1 − 1.5·IQR или x > Q3 + 1.5·IQR Непараметрический метод, устойчив к выбросам. Стандарт в статистике.

6.3. MAD-метод

MAD = median(|xᵢ − median(x)|) Выброс: |xᵢ − median(x)| > 3·MAD Робастная альтернатива z-score. Менее чувствителен к выбросам.

7.Структура и неравенство

7.1. HHI — индекс Херфиндаля–Хиршмана

HHI = Σ sᵢ² sᵢ — доля региона в процентах (0…100). Диапазон: 0…10 000. Интерпретация: <1000 — низкая концентрация; 1000–1800 — умеренная; 1800–2500 — высокая; >2500 — очень высокая.

7.2. Индекс Джини

G = Σᵢ (2i − n − 1) · x₍ᵢ₎ / (n · Σx) x₍ᵢ₎ — отсортированы по возрастанию. 0 — полное равенство, 1 — один регион забирает всё.

7.3. CR-k — концентрация

CR_k = (Σ топ-k значений / Σ всех значений) × 100% Доля топ-k в общей сумме. Используется вместе с HHI.

7.4. Энтропия Шеннона

H = −Σ pᵢ · ln(pᵢ) pᵢ = xᵢ / Σx. Мера разнообразия. Максимум — при равных долях. Больше — равномернее.

8.Корреляции

8.1. Коэффициент Пирсона

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²] Линейная корреляция от −1 до +1. |r| < 0.3 — слабая; 0.3–0.7 — умеренная; > 0.7 — сильная. Считается только по общим годам.

8.2. Корреляции с лагом

r(k) = corr(X_t, Y_{t+k}) k — лаг в годах (0, 1, 2, 3). Позволяет выявить отложенные зависимости между регионами.

9.Временные ряды

9.1. ACF — автокорреляционная функция

ρ(k) = Σ(xᵢ − x̄)(xᵢ₊ₖ − x̄) / Σ(xᵢ − x̄)² Показывает зависимость между значениями ряда на расстоянии k лет.

9.2. Тест Манна–Кендалла

S = Σᵢ Σⱼ₌ᵢ₊₁ sign(xⱼ − xᵢ) Var(S) = n(n−1)(2n+5) / 18 Z = (S − sign(S)) / √Var(S) p-value ≈ 2·(1 − Φ(|Z|)) Непараметрический тест на наличие монотонного тренда. |Z| > 1.96 — значимый тренд (уровень 5%).

9.3. Скользящее среднее

MA_t = (x_{t−w+1} + … + x_t) / w w — размер окна (3 или 5 лет). Для первых лет окно усекается.

10.Кластеризация и PCA

10.1. k-means (k = 3)

1. Инициализация центров (k-means++) 2. Назначение точек ближайшему центру 3. Пересчёт центров как средних 4. Повтор до сходимости (не более 50 итераций) Входные данные — нормированные на максимум ряды. Случайная инициализация: результат может отличаться между запусками.

10.2. PCA — метод главных компонент

1. Центрирование данных (вычитание среднего) 2. Ковариационная матрица 3. Степенной метод для двух главных собственных векторов 4. Проекция точек в 2D Позволяет визуально оценить группы похожих регионов.

11.Допущения и ограничения

11.1. Общие допущения

  • Все значения — в млрд кВт·ч.
  • Год — целое число от 1990 до 2100.
  • Значение — неотрицательное, не более 100 000.
  • Статус «факт», «оценка», «прогноз».

11.2. Допущения при прогнозировании

  • Структурные сдвиги (ввод/вывод мощностей, аварии, реформы) не учитываются.
  • Прогноз — экстраполяция прошлых тенденций.
  • МНК при n < 3 точках недостоверен.
  • Полином-2 при n < 5 точках может давать неустойчивые результаты.

11.3. Допущения при корреляциях

  • Корреляция не означает причинно-следственную связь.
  • Пирсон требует общих лет; при малом количестве (n < 5) значения ненадёжны.
Важно. Прогнозы, кластеризация и корреляции — инструменты поддержки принятия решений, а не готовые ответы. Перед использованием в официальных отчётах требуется экспертная интерпретация.
