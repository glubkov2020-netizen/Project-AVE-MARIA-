Методика расчётов

Версия: 6.1 Дата: 2026 Область: солнечная генерация РФ

1.Введение

Документ описывает все математические методы, применяемые в СППР «Солнечная Энергетика РФ». Каждая формула сопровождается описанием обозначений, допущений и примеров.

Открытость. Все формулы открыты, реализованы в JavaScript, доступны для проверки в консоли браузера. При расхождении с ручным расчётом — приоритет за ручным.

3.Описательные статистики

3.1. Среднее арифметическое

x̄ = (Σ xᵢ) / n n — число наблюдений; xᵢ — i-е значение. Чувствительно к выбросам.

3.2. Медиана

Me = x₍₍ₙ₊₁₎/₂₎ (нечётное n) Me = (x₍ₙ/₂₎ + x₍ₙ/₂₊₁₎) / 2 (чётное n) Устойчива к выбросам.

3.3. Стандартное отклонение

σ = √[ Σ (xᵢ − x̄)² / (n − 1) ] Поправка Бесселя.

3.4. Коэффициент вариации

CV = (σ / x̄) × 100%

3.5. CAGR — среднегодовой темп

CAGR = [(x_end / x_start)^(1/n) − 1] × 100% Только если оба значения положительные.

4.Тренды и прогнозы

4.1. Линейный тренд (МНК)

ŷ = a + b·t b = Σ (tᵢ − t̄)(yᵢ − ȳ) / Σ (tᵢ − t̄)² a = ȳ − b·t̄

4.2. Полиномиальный тренд 2-й степени

ŷ = a₀ + a₁·t + a₂·t²Метод Гаусса.

4.3. Экспоненциальный тренд

ŷ = a · e^(b·t)МНК по ln(y).

4.4. Прогноз

ŷ_прогноз(t) = модель(t) для t > t_lastЭкстраполяция.

5.Качество модели

5.1. R²

R² = 1 − SS_res / SS_tot

5.2. MAPE

MAPE = (100/n) × Σ |(yᵢ − ŷᵢ) / yᵢ|

6.Аномалии

6.1. z-score

z = (x − x̄) / σ|z| > 2 — выброс; |z| > 3 — сильный.

6.2. IQR

IQR = Q3 − Q1 Выброс: x < Q1 − 1.5·IQR или x > Q3 + 1.5·IQR

6.3. MAD

MAD = median(|xᵢ − median(x)|) Выброс: |xᵢ − median(x)| > 3·MAD

7.Структура и неравенство

7.1. HHI

HHI = Σ sᵢ²sᵢ — доля в %. Диапазон 0…10000.

7.2. Джини

G = Σᵢ (2i − n − 1) · x₍ᵢ₎ / (n · Σx)

7.3. CR-k

CR_k = (Σ топ-k / Σ всех) × 100%

7.4. Энтропия Шеннона

H = −Σ pᵢ · ln(pᵢ)

8.Корреляции

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²] |r| < 0.3 — слабая; 0.3–0.7 — умеренная; > 0.7 — сильная.

9.Временные ряды

9.1. ACF

ρ(k) = Σ(xᵢ − x̄)(xᵢ₊ₖ − x̄) / Σ(xᵢ − x̄)²

9.2. Манн–Кендалл

S = Σᵢ Σⱼ₌ᵢ₊₁ sign(xⱼ − xᵢ) Var(S) = n(n−1)(2n+5) / 18 Z = (S − sign(S)) / √Var(S) |Z| > 1.96 — значимый тренд (5%).

11.Экономика СЭС — формулы

Раздел «3.1 Окупаемость СЭС» рассчитывает ключевые показатели инвестиционного проекта солнечной электростанции. Методология: IEA LCOE, Lazard v16, IRENA. Все расчёты — в числах с плавающей точкой, без промежуточного округления.

11.1. Годовая выработка

E_t = P × 1000 × Y_удельн × f_deg(t) P — мощность СЭС, МВт; Y_удельн — удельная выработка, кВт·ч/кВт·год; f_deg(t) — фактор деградации на год t. P × 1000 переводит МВт в кВт. Типичный Y_удельн для юга РФ — 1300–1600 кВт·ч/кВт·год.

11.2. Фактор деградации — два режима

Линейная: f_deg(t) = max(0, 1 − d × (t − 1)) Экспоненциальная: f_deg(t) = (1 − d)^(t − 1) d — годовая деградация (доля, например 0.005 для 0.5%/год). Линейная — консервативный вариант (деградация равномерно). Экспоненциальная — компаундная (в начале быстрее).

11.3. Тариф и выручка

T_t = T_0 × (1 + g_T)^(t − 1) R_t = E_t × T_t T_0 — начальный тариф, ₽/кВт·ч; g_T — ежегодный рост тарифа (доля).

11.4. OPEX

OPEX_t = CAPEX × opex% × (1 + g_O)^(t − 1) CAPEX — капитальные затраты, ₽; opex% — доля операционных затрат в год; g_O — рост OPEX (доля).

11.5. EBITDA и налог на прибыль

EBITDA_t = R_t − OPEX_t + S_t Tax_t = max(0, EBITDA_t × τ) S_t — субсидия / ДПМ ВИЭ, ₽/год; τ — ставка налога на прибыль (20% для РФ по умолчанию). Упрощение: амортизация и проценты по долгу не учитываются. Отрицательная EBITDA даёт налоговый щит 0.

11.6. Чистый денежный поток и дисконтирование

CF_t = EBITDA_t − Tax_t DF_t = 1 / (1 + r)^t DCF_t = CF_t × DF_t r — ставка дисконтирования (доля).

11.7. NPV — чистый приведённый доход

NPV = −CAPEX + Σₜ₌₁ᴺ DCF_t NPV > 0 — целесообразно; NPV < 0 — нецелесообразно.

11.8. Срок окупаемости (простой и дисконтированный)

Простой: PB = min{ T : Σₜ₌₁ᵀ CF_t ≥ CAPEX } Дисконтированный: DPB = min{ T : Σₜ₌₁ᵀ DCF_t ≥ CAPEX } С линейной интерполяцией внутри года окупаемости.

11.9. IRR — внутренняя норма доходности

IRR = r* : NPV(r*) = 0 Метод бисекции на интервале (-99%, 1000%). IRR > ставки дисконтирования — проект эффективен.

11.10. MIRR — модифицированная IRR

MIRR = [ FV_positive / PV_negative ]^(1/N) − 1 FV_positive — будущая стоимость положительных потоков по ставке реинвестирования; PV_negative — текущая стоимость отрицательных потоков по ставке дисконтирования.

11.11. LCOE — приведённая стоимость электроэнергии

LCOE = ( CAPEX + Σₜ₌₁ᴺ OPEX_t / (1+r)^t ) / Σₜ₌₁ᴺ E_t / (1+r)^t Формула IEA для levelized cost of electricity. Учитывает дисконтирование как затрат, так и выработки.

11.12. PI — индекс доходности

PI = (NPV + CAPEX) / CAPEX PI > 1 — проект эффективен.

11.13. WACC — средневзвешенная стоимость капитала

WACC = w_d × r_d × (1 − τ) + w_e × r_e w_d — доля долга; r_d — ставка по долгу; w_e — доля собственного капитала; r_e — стоимость собственного капитала. Если пользователь выбрал «рассчитывать ставку дисконтирования через WACC», поле ставки обновляется автоматически.

11.14. Чувствительность NPV

Тепловая карта NPV по сетке:

  • тариф: −30%, −20%, −10%, 0, +10%, +20%, +30% от базового;
  • ставка дисконтирования: 5%, 8%, 10%, 12%, 15%, 18%, 20%, 25%.
NPV(r, T_база × (1+δ)) — для каждой пары (r, δ) Позволяет оценить, при каких отклонениях проект остаётся рентабельным.
Важно. Расчёт экономики — оценочный. Не учитывает: субсидии сверх указанных, зелёные сертификаты, сезонность, ограничения сети, локальные климатические особенности, инфляцию сверх указанных темпов, амортизацию и долговое финансирование (упрощение). Для инвестиционного решения требуется ТЭО.

12.Допущения и ограничения

  • Все значения — в млн кВт·ч.
  • Год — целое число от 1990 до 2100.
  • Значение — неотрицательное, не более 100 000.
  • Статусы: «факт», «оценка», «прогноз».
  • Структурные сдвиги (ввод/вывод мощностей) при прогнозировании не учитываются.
  • Корреляция не означает причинно-следственную связь.
  • МНК при n < 3 недостоверен.
  • Полином-2 при n < 5 может быть неустойчив.
  • Экономика — упрощённая (без налоговых щитов через амортизацию, без долгового финансирования в CF).
Важно. Прогнозы, кластеризация, корреляции и экономические расчёты — инструменты поддержки принятия решений, а не готовые ответы. Перед использованием в официальных отчётах требуется экспертная интерпретация.
