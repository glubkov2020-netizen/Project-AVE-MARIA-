1. О платформе

Выработка ЭЭ по регионам РФ — аналитическая платформа для работы с данными о годовой выработке электроэнергии по субъектам Российской Федерации. Работает полностью в браузере, без серверной части и без передачи данных.

Ключевые принципы

  • Полностью клиентская работа. Все расчёты в браузере. Данные не отправляются на серверы.
  • Открытые формулы. Каждая метрика описана ниже, её можно проверить вручную.
  • Честные данные. Прогнозы помечены явно, экстраполяции не выдаются за факты.
  • Официальное оформление. PDF/DOCX/HTML под документооборот организации.
  • Автосохранение в localStorage (при согласии пользователя).

Технологии

  • Plotly.js — интерактивные графики
  • SheetJS — XLSX
  • docx — DOCX
  • JSZip — ZIP
  • Vanilla JS — всё остальное (без фреймворков)

2. Быстрый старт

Шаг 1. Загрузите данные

  • Кнопка «Загрузить базу» — если рядом с index.html лежит файл data.js с seed-данными.
  • Вручную — «+ Строка» в таблице.
  • CSV/JSON — вставка в поле «Вставка CSV / TSV / JSON».
  • Файл — .csv, .tsv, .json, .xlsx.
  • Демо — синтетика для теста.

Шаг 2. Проверьте качество

Раздел «Паспорт данных» — заполненность, пропуски, скачки, статусы.

Шаг 3. Анализируйте

Графики, сравнение, расчёты, тренды, продвинутая аналитика, структура, аномалии, тепловые карты, паспорт региона, сценарии.

Шаг 4. Оформите отчёт

«Оформление» → заполните организацию, автора, дату, город. Затем «Экспорт» → PDF / DOCX / HTML.

Шаг 5. Сохраните проект

«Настройки» → «Скачать проект (JSON)». Позже загрузите — восстановится всё.

3. Данные и форматы

Схема

{
  region: string,   // название региона
  year: number,     // 1990–2100
  value: number,    // млрд кВт·ч, ≥ 0
  status: "факт" | "оценка" | "прогноз",
  note: string      // источник/примечание
}

CSV

Регион;Год;Значение;Статус;Примечание
Кемеровская обл.;2019;34.5;факт;Отчёт Минэнерго 2019
Москва;2019;68.2;факт;Мосэнерго
Москва;2020;65.4;оценка;

Разделитель: ; или , или табуляция — определяется автоматически.

JSON

[{"region":"Кемеровская обл.","year":2019,"value":34.5,"status":"факт","note":"Отчёт"}]

Единицы

Внутренне всё хранится в млрд кВт·ч. При отображении можно конвертировать в млн кВт·ч или ТВт·ч (Настройки → Единица).

Проверки при импорте

  • Год: 1990–2100
  • Значение: ≥ 0 и ≤ 100 000
  • Дубликаты (регион+год) — предупреждение
  • Будущий год со статусом «факт» — предупреждение
  • Неизвестный регион — добавляется автоматически

5. Формулы и методы

Описательные статистики

Среднееx̄ = (Σ xᵢ) / n
Медиананечётное n: x₍ₙ₊₁₎/₂ чётное n: (x₍ₙ/₂₎ + x₍ₙ/₂₊₁₎) / 2
σ (выборочное)σ = √[Σ(xᵢ − x̄)² / (n − 1)]
CVCV = (σ / x̄) · 100%
CAGRCAGR = [(x_кон / x_нач)^(1/n) − 1] · 100% n — число лет между крайними

Тренды

Линейный (МНК)ŷ = a + b·t b = Σ(tᵢ − t̄)(yᵢ − ȳ) / Σ(tᵢ − t̄)² a = ȳ − b·t̄
Полином 2ŷ = a₀ + a₁·t + a₂·t² (МНК через Гаусса)
Экспонентаŷ = a · e^(b·t) (МНК к ln y)
R²R² = 1 − SS_res / SS_tot
MAPEMAPE = (100/n) · Σ |(yᵢ − ŷᵢ) / yᵢ|

Аномалии

z-scorez = (x − x̄) / σ |z| > 2 — выброс, |z| > 3 — сильный
IQRQ1, Q3 IQR = Q3 − Q1 Выброс: x < Q1 − 1.5·IQR или x > Q3 + 1.5·IQR
MADMAD = median(|xᵢ − median(x)|) Выброс: |xᵢ − median(x)| > 3·MAD

Структура

HHIHHI = Σ sᵢ², sᵢ = доля в % 0 – 10 000
ДжиниG = Σᵢ(2i − n − 1)·x₍ᵢ₎ / (n·Σx) 0 — равенство, 1 — один регион
CR-kCR_k = (Σ топ-k / Σ всех) · 100%
ЭнтропияH = −Σ pᵢ·ln(pᵢ)

Корреляции и временные ряды

Пирсонr = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²] |r| < 0.3 — слабая, 0.3–0.7 — умеренная, > 0.7 — сильная
ACFρ(k) = Σ(xᵢ−x̄)(xᵢ₊ₖ−x̄) / Σ(xᵢ−x̄)²
Манн-КендаллS = ΣᵢΣⱼ₌ᵢ₊₁ sign(xⱼ − xᵢ) Var(S) = n(n−1)(2n+5)/18 Z = (S − sign(S)) / √Var(S) |Z| > 1.96 — значимый тренд (5%)

Кластеризация и PCA

8. Экспорт

Форматы

  • PNG / JPEG / WEBP — растровые изображения (1600×900, белый фон)
  • SVG — вектор
  • PDF — открывается в новом окне, Ctrl+P → «Сохранить как PDF»
  • HTML — самодостаточный отчёт
  • DOCX — Word с титулом и таблицами
  • CSV — данные, разделитель ;, UTF-8 BOM
  • XLSX — многолистовой
  • JSON — полный снимок
  • Markdown — .md
  • ZIP — архив: по одному CSV на регион

Режимы

  • Краткий — титул, график, сводная, динамика, приложение
  • Полный — + тренды, методическая справка

9. Согласие и персональные данные

Платформа не собирает персональные данные. Всё работает в браузере. Никакие данные не отправляются на серверы.

Что хранится в localStorage

  • Введённые данные (для автосохранения)
  • Настройки (единицы, точность, разделитель, тема)
  • Флаг согласия

Управление

  • Принять всё: автосохранение + восстановление при следующем открытии
  • Только необходимые: автосохранение отключено
  • Отозвать согласие: Настройки → «Согласие и cookies»

Cookie

Платформа не использует HTTP-cookies. localStorage — это не cookies, но подпадает под требования согласия.

10. Ограничения

  • Данные — результат ввода пользователя. Платформа не содержит официальных данных.
  • Seed-база data.js содержит оценочные цифры — требуют проверки.
  • Прогнозы — линейная/полином/экспонента, без структурных сдвигов.
  • localStorage: ~5 МБ на домен.
  • Интернет нужен при первом открытии (CDN).
  • МНК при < 3 точках недостоверен.
  • k-means случайная инициализация — результат может отличаться.

11. FAQ

Данные отправляются на сервер?

Нет. Всё в браузере. Автосохранение — в localStorage (при согласии).

PDF без кракозябр?

Да, через печать браузера — системный шрифт.

Как добавить свой регион?

Введите название вручную в таблице — добавится автоматически.

Работает на телефоне?

Да. Нижняя панель навигации, крупные кнопки, инпуты 16px.

Где seed-данные?

В файле data.js рядом с index.html. Кнопка «Загрузить базу».

Можно ли использовать оффлайн?

После первой загрузки — да, при условии что браузер закешировал библиотеки.
