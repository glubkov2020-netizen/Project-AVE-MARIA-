Руководство пользователя

Версия: 6.1 Дата: 2026 Область: солнечная генерация РФ

1.Общие сведения

СППР «Солнечная Энергетика РФ» — система поддержки принятия решений о строительстве солнечных электростанций в Российской Федерации. Работает полностью в браузере, без серверной части, без передачи данных третьим лицам.

Назначение

  • Сбор и нормализация данных о выработке СЭС по регионам РФ.
  • Построение официальных графиков и аналитических отчётов.
  • Статистический анализ: динамика, тренды, аномалии, структура, корреляции.
  • Оценка экономической целесообразности проекта СЭС (NPV, IRR, MIRR, LCOE, PI).
  • Сценарное моделирование и прогнозирование.
  • Экспорт в 12 форматов, включая PDF, DOCX, XLSX, ZIP.

Ключевые принципы

  • Только солнечная генерация. В базе — регионы РФ с действующими СЭС.
  • Официальные источники. Приоритет — СО ЕЭС и Минэнерго России.
  • Открытые формулы. Каждая метрика описана в Методике.
  • Автосохранение в localStorage (при согласии пользователя).

2.Быстрый старт

  1. Загрузите данные: раздел 1.1 Ввод данных СЭС → «Загрузить базу СЭС» или вставьте CSV/JSON.
  2. Проверьте качество: раздел 1.2 Качество данных.
  3. Постройте графики: раздел 2.1 Графики выработки. Выделите область мышью для приближения, двойной клик — сброс.
  4. Постройте тренды: раздел 2.4 Тренды и прогнозы.
  5. Оцените экономику: раздел 3.1 Окупаемость СЭС.
  6. Сформируйте отчёт: разделы 4.1 Оформление → 4.2 Экспорт.

3.Форматы данных

3.1. Схема записи

{
  region: string,    // название региона
  year: number,      // 1990–2100
  value: number,     // млн кВт·ч
  status: "факт" | "оценка" | "прогноз",
  note: string       // источник
}

3.2. CSV

Регион;Год;Значение;Статус;Примечание
Оренбургская обл.;2023;440;факт;СО ЕЭС
Астраханская обл.;2023;320;факт;СО ЕЭС

3.3. Единицы измерения

Внутренне — млн кВт·ч. Переключение в Настройках: млн / млрд / ТВт·ч.

6.Экономика СЭС

Раздел 3.1 рассчитывает окупаемость и целесообразность. Введите:

  • Мощность СЭС (МВт)
  • Удельная выработка (кВт·ч/кВт·год) — типично 1300–1600 для юга РФ
  • CAPEX (млн ₽) — типично 70–100 млн ₽ за 1 МВт
  • OPEX (% CAPEX/год) — типично 1–2%
  • Рост OPEX (%/год)
  • Тариф (₽/кВт·ч)
  • Рост тарифа (%/год)
  • Тип деградации: линейная / экспоненциальная
  • Деградация панелей (%/год) — 0.5–0.7%
  • Ставка дисконтирования (%) — либо через WACC
  • Срок жизни (25–30 лет)
  • Налог на прибыль (%) — 20% по умолчанию
  • Субсидия / ДПМ ВИЭ (млн ₽/год)

Результаты:

  • Срок окупаемости (простой и дисконтированный) — главный показатель.
  • NPV, IRR, MIRR, LCOE, PI, вердикт о целесообразности.
  • KPI: годовая выработка, суммарный CF, суммарная выручка, суммарный OPEX, суммарный налог, среднегодовой CF.
  • Три графика: накопительный CF, годовая динамика, DCF и NPV-кривая.
  • Детальная таблица по годам: выработка, тариф, выручка, OPEX, субсидия, EBITDA, налог, CF, DF, DCF, накопленные значения.
  • Экспорт таблицы в CSV и JSON.
  • Тепловая карта чувствительности NPV к тарифу и ставке дисконтирования.
Совет. Если NPV < 0, но PI близок к 1 — попробуйте уменьшить ставку дисконтирования (например, льготный займ) или увеличить тариф (например, зелёный тариф).
