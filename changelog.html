Политика конфиденциальности и cookies

Версия: 5.0 Дата: 2026 Область: Платформа «Выработка ЭЭ по регионам РФ»

1. Общие положения

Настоящая Политика описывает, какие данные обрабатываются на платформе «Выработка ЭЭ по регионам РФ» (далее — «Платформа»), каким образом и с какой целью.

Ключевое. Платформа не собирает и не передаёт персональные данные третьим лицам. Все вычисления выполняются на стороне пользователя в браузере.

2. Какие данные обрабатываются

2.1. Что НЕ обрабатывается

  • IP-адреса
  • Cookies (HTTP)
  • Данные геолокации
  • Данные учётных записей
  • Поведенческие метрики (аналитика)
  • Любые данные, передаваемые на сервер

3. localStorage — что это

localStorage — механизм браузера для хранения данных в виде пар «ключ — значение» на стороне клиента. Данные сохраняются между сессиями и не передаются на сервер.

4. Согласие пользователя

При первом открытии Платформы появляется баннер с двумя вариантами:

  • «Принять» — разрешает автосохранение данных и настроек в localStorage.
  • «Только необходимые» — автосохранение отключается. Данные хранятся только в памяти вкладки до закрытия.

4.1. Отзыв согласия

Отозвать согласие можно в любой момент: «Настройки → Согласие и cookies → Отозвать». При отзыве все сохранённые данные удаляются из localStorage.

4.2. Удаление вручную

Пользователь может самостоятельно очистить данные в браузере:

  • Chrome / Edge: Настройки → Конфиденциальность → Очистить данные → Cookies и другие данные сайтов
  • Firefox: Настройки → Приватность → Cookies и данные сайтов → Управление
  • Safari: Настройки → Конфиденциальность → Управление данными сайтов

5. Cookies (HTTP)

Платформа не использует HTTP-cookies. Все данные хранятся в localStorage, который, хотя формально не является cookies, подпадает под требования согласия на хранение данных.

6. Передача третьим лицам

Платформа не передаёт данные третьим лицам. Единственные внешние запросы — загрузка библиотек с CDN (Cloudflare, jsDelivr) при первом открытии. Эти запросы не содержат данных пользователя.

7. Хранение и защита

Данные в localStorage хранятся в браузере пользователя. Платформа не имеет доступа к данным других сайтов и не может читать данные вне своего домена.

При использовании общего устройства другие пользователи могут видеть сохранённые данные. Для чувствительных сценариев рекомендуется выбирать «Только необходимые» при первом открытии.

8. Права пользователя

  • Знать, какие данные обрабатываются (раздел 2).
  • Отозвать согласие в любой момент (раздел 4.1).
  • Удалить сохранённые данные вручную (раздел 4.2).
  • Использовать платформу без сохранения — выбрать «Только необходимые».

9. Изменения в Политике

Политика может обновляться. Актуальная версия всегда доступна на этой странице. Существенные изменения отмечаются в истории версий.

10. Контакт

По вопросам, связанным с обработкой данных, обращайтесь через репозиторий проекта (GitHub Issues) или страницу правовой информации.
