Политика данных и cookies

Версия: 6.1Дата: 2026Область: СППР «Солнечная Энергетика РФ»

1. Общие положения

Настоящая Политика описывает, какие данные обрабатываются в СППР «Солнечная Энергетика РФ», каким образом и с какой целью.

Ключевое. Платформа не собирает и не передаёт персональные данные третьим лицам. Все вычисления выполняются на стороне пользователя в браузере.

2. Какие данные обрабатываются

Тип данныхГде хранятсяЦель
Введённые пользователем значения (регион, год, значение, статус, примечание)localStorage браузераАвтосохранение при согласии
Настройки (единица, точность, тема)localStorageСохранение предпочтений
Параметры экономики (мощность, CAPEX, тариф и др.)localStorageСохранение расчётов
Флаг согласияlocalStorageНе показывать баннер повторно
Журнал действий (в текущей сессии)Память браузераДиагностика ошибок

2.1. Что НЕ обрабатывается

  • IP-адреса
  • HTTP-cookies
  • Данные геолокации
  • Данные учётных записей
  • Поведенческие метрики
  • Любые данные, передаваемые на сервер

3. localStorage

localStorage — механизм браузера для хранения данных на стороне клиента. Ключи платформы:

КлючСодержимое
solar_rf_stateДанные пользователя, настройки, тема, параметры экономики
solar_rf_consent_v6Флаг согласия
solar_rf_onbФлаг онбординга

4. Согласие пользователя

При первом открытии появляется баннер с двумя вариантами:

  • «Принять» — разрешает автосохранение в localStorage.
  • «Только необходимые» — автосохранение отключается.

Отозвать согласие: «4.3 Настройки → Согласие и cookies».

5. Передача третьим лицам

Единственные внешние запросы — загрузка библиотек с CDN при первом открытии:

РесурсНазначение
Plotly.js (cdn.plot.ly)Графики
SheetJS (cdn.jsdelivr.net)XLSX
docx (cdn.jsdelivr.net)DOCX
JSZip (cdn.jsdelivr.net)ZIP

6. Права пользователя

  • Знать, какие данные обрабатываются.
  • Отозвать согласие в «Настройках».
  • Удалить данные вручную через браузер.
  • Использовать платформу без сохранения — выбрать «Только необходимые».
